纸阅是一个本地优先、最小权限的开源小说阅读器（Android）。编码识别、章节切分、正文提取、语音朗读全部在本机完成——你的书籍与阅读记录只存在你自己的设备上。

== 核心功能 ==

* 本地导入 TXT / EPUB：智能章节解析（强正则 + 启发式 + 强制分段回退），编码自动探测（BOM → UTF-8 → GB18030 回退），GBK 老书不乱码，导入结果页可手动切换编码重新解析
* 大文件流式导入：200 MB 级 TXT 常驻内存与文件大小无关，按章懒加载，翻到哪读到哪
* 舒适排版：5 套预设主题（纸白 / 米黄 / 苔绿 / 黛蓝 / 墨黑）、字号 / 行距 / 段距 / 边距实时生效、亮度与屏幕常亮、沉浸模式、连续滚动与仿真翻页两种翻页方式、平板自动双页跨页
* 进度记忆：段级 + 像素级恢复，退出重开精确回到原位置；字符加权进度，章节长短不均也不跳变
* 全书搜索：在当前书内按关键词流式搜索，结果定位到段并高亮，可随时取消、不改动阅读进度
* 书签与备注：书签按章分组，每条可写 ≤ 500 字备注
* 自定义字体：导入本机 TTF / OTF 字体用于正文，文件缺失或损坏自动回退默认字体
* TTS 语音听书：系统 TTS 引擎离线合成，做饭 / 通勤时「听书」；段落高亮跟随、语速音调可调、章尾自动续读、后台常驻播放（通知栏控制）
* 局域网传书：同一 WiFi 下把书多选传给另一台纸阅，不依赖数据线 / 云盘
* 换机迁移：整库（书籍 + 进度 + 书签）打包为单一文件迁移到新设备
* 进度同步：两台设备双向交换阅读位置与书签，冲突按「最后阅读时间较新者胜」
* 本地备份 / 恢复：书架打包为 zip 导出到本机任意位置，可选口令加密（PBKDF2 派生密钥 + 条目级 AES-256-GCM），恢复逐本走导入流水线并给出失败明细
* 反馈友好：一键导出诊断包（应用版本 / 设备型号 / 错误堆栈，脱敏后不含书籍内容与个人信息），附在 GitHub Issue 里帮维护者定位问题

== 隐私承诺 ==

* 无账号：不需要注册登录，应用没有用户系统
* 无云同步：阅读数据仅存储在本机，没有云端服务器
* 无遥测：不收集、不上传任何使用统计与个人信息
* 不访问公网：唯一的网络通信是你在同一局域网内主动发起的传书 / 迁移 / 同步，全部落在你自己的路由器内；不内置任何远程接口调用，不加载远程资源

权限说明（最小权限，共 4 项）：
* INTERNET——Android 没有「仅局域网」权限，任何 socket（含连接局域网 IP）都必须声明它；HTTP 服务仅绑定 WiFi 网卡地址
* FOREGROUND_SERVICE / FOREGROUND_SERVICE_MEDIA_PLAYBACK / POST_NOTIFICATIONS——仅用于朗读退到后台后继续播放并在通知栏控制，语音由系统 TTS 引擎在本机离线合成

完整隐私政策见仓库 PRIVACY.md 与应用内「隐私说明」页；网络行为经 CI 静态断言可验证，审计文档公开在 docs/NETWORK_AUDIT.md。
