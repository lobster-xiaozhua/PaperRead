## 已决决策（留档）

- **Wi-Fi 传书（C9）**：2026-10-18 用户拍板——项目允许申请权限、保持最小权限；INTERNET 进主包（Android 无「仅局域网」权限，任何 socket 均需声明），传书 / 迁移 / 同步只在同一局域网内进行，不访问公网；分发拆 client（客户端正式版）/ dev（调试版）两个 flavor，可同机安装。传输能力进主包，不再保留零权限包。
- **TTS 朗读（C2）**：2026-10-19 用户拍板——接入系统 TextToSpeech（`android.speech.tts`），零新增依赖、不访问网络；生命周期选**后台常驻播放**，接受前台服务三件套权限（`FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MEDIA_PLAYBACK` / `POST_NOTIFICATIONS`，隐私文案同步更新）；章尾自动续读**默认开启、可关**。人工把关项（权限 / 并发 / 数据模型）备案见 TASKS T6，验收标准见 SPEC 第 10 节（AC-12.1 – AC-12.8）。
