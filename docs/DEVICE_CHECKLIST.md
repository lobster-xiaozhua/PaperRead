# 纸阅 PaperRead 装机验证清单

> 适用版本：v1.0.1（versionCode 2，minSdk 26 / targetSdk 35）
> 第 7 节（B1 流式导入）需安装含 B1 的开发版 APK 验证；其余节适用于 v1.0.1 发布版
> 验证目标设备：至少一台 Android 8.0（API 26）真机；建议覆盖 Android 13/14/15 各一台
> 隐私红线：全程开启飞行模式或断网验证，应用**不得**出现任何网络行为

## 0. 安装

- [ ] `adb install -r app-debug.apk`（或 release 签名后安装 `app-release.apk`）成功
- [ ] 桌面图标正常显示（自适应图标；Android 13+ 可见单色主题图标）
- [ ] 首次启动进入书架页，无崩溃
- [ ] 系统设置 → 应用 → 纸阅 → 权限：**未申请任何权限**（无 INTERNET、无存储权限——SAF 按需授权）

## 1. 导入（AC-1.x / AC-2.x）

- [ ] 点击右下角导入按钮，系统文件选择器弹出
- [ ] 选择一本 **GBK 编码 TXT**（≥2 MB，含目录页）：导入完成后书架出现书籍，封面为程序化渐变 + 首字
- [ ] 进入书籍，章节标题无乱码、正文无乱码
- [ ] 重复导入同一文件：弹出「书籍已存在」对话框，可选「替换」或「取消」；选「替换」后旧书进度与书签被清除并完成导入
- [ ] 导入大文件期间点击「取消导入」或对话框外部：导入中止，书架无残留书籍，临时文件已清理
- [ ] 选择一本 **EPUB**：导入成功，章节顺序与原书目录一致
- [ ] 选择加密 EPUB（如有）：提示「DRM 加密不支持」
- [ ] 选择非 txt/epub 文件（如 pdf）：提示格式不支持
- [ ] 长按书籍 → 重新解析 → 切换「激进」策略：章节数变化符合预期，无文本丢失；进度与书签被重置（旧书签已清空）

## 2. 书架（AC-3.x）

- [ ] 「继续阅读」卡片展示最近阅读书籍与进度
- [ ] 点击卡片进入阅读器，停在上次段落
- [ ] 长按书籍进入多选，可批量删除；删除后书架与数据库一致
- [ ] 排序切换：最近阅读 / 添加时间 / 书名 / 进度，四种均生效

## 3. 阅读器（AC-4.x）

- [ ] 正文按段落排版，两端对齐（Justify）
- [ ] 点击屏幕中央：顶/底工具栏唤出；再次点击收起
- [ ] 底栏「上一章 / 下一章」可切换；章末有「下一章」入口
- [ ] 目录按钮：章节列表弹出，**当前章高亮**，点击任意章跳转
- [ ] 设置按钮：5 套主题（纸白/米黄/苔绿/黛蓝/墨黑）切换即时生效
- [ ] 字号 / 行距 / 段距 / 页边距 Slider 拖动即时重排
- [ ] 亮度：开启手动调节后屏幕亮度变化；关闭后恢复跟随系统
- [ ] 「阅读时常亮」开启后阅读时不熄屏
- [ ] 「沉浸模式」开启后系统栏隐藏；点击正文唤出工具栏时系统栏临时显示
- [ ] 「音量键翻章」默认**关闭**（按音量键只调系统音量）；设置开启后音量下键=下一章、上键=上一章
- [ ] 杀掉进程重进：恢复到期号与段落，进度百分比与退出前一致（500ms 防抖内的最后位置允许丢失）

## 4. 书签（AC-6.x）

- [ ] 阅读中点击顶栏星标：Snackbar 提示「已添加书签」
- [ ] 目录 → 书签 Tab：书签按时间倒序显示，含章节名、摘录、时间
- [ ] 点击书签：跳转到书签章节与段落
- [ ] 点击书签尾部删除图标：书签移除
- [ ] 删除书籍后其书签一并删除（级联）

## 5. 进度与恢复（AC-5.x）

- [ ] 阅读至书中段，下拉「最近任务」划掉应用，重进书架 → 继续阅读 → 停在同一段落
- [ ] 旋屏：阅读位置保持（LazyListState 经 rememberSaveable 恢复）
- [ ] 长短章不均的书：进度百分比连续变化，无「章数百分比」式跳变

## 6. 隐私与稳定性

- [ ] 全程飞行模式：导入、阅读、书签、设置全部正常
- [ ] `adb shell dumpsys package io.github.lunalight.paperread | grep permission`：无 android.permission.INTERNET
- [ ] 导入一本 50 MB+ TXT：无 OOM、无 ANR，切章流畅（双偏移懒加载）
- [ ] logcat 过滤 `E/AndroidRuntime`：无崩溃；` StrictMode` 无磁盘读写主线程警告（如有请记录）

## 7. B1 流式导入专项（200 MB GBK）

> 前置：B1 代码已完成（115 单测全绿 + lint 0/0），本节为真机验收。200 MB GBK 文件可用脚本拼接生成（保持 GBK 编码，含目录页与长短不一章）。

- [ ] 导入 200 MB GBK TXT：**导入成功**，书架出现书籍，无 OOM / 无 ANR
- [ ] 导入全程进度对话框百分比平滑推进，无超过 2 秒的卡顿
- [ ] 导入期间另一终端周期执行 `adb shell dumpsys meminfo io.github.lunalight.paperread | grep -i "TOTAL PSS"`：导入全程峰值 **< 100 MB**
- [ ] 章节数与 PC 端按同策略（保守）批量切分数量一致（可用 `adb shell` 拉取 `files/books/<id>/chapters.json` 对比）
- [ ] 进入书籍：首章 / 末章标题与正文无乱码；跳至末章进度百分比 ≈ 100%，与退出重进一致
- [ ] `book.txt` 大小 = 原文件按探测编码解码后的字节数（`adb shell stat` 对比）；logcat 无 `E/AndroidRuntime`

## 8. 已知限制（非阻塞）

- TXT 作者恒为「未知」（正文作者行解析未实现）
- 目录页与正文首章标题无空行分隔时，极端重复场景首个标题可能归入目录块（文本不丢失，可激进重解析修复）
- 亮度手动调节仅在阅读器内生效，退出后恢复系统值
